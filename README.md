# Wynford Roadside Assistance website

Website for **Wynford Roadside Assistance**, a 24/7 towing and roadside company in North York, Toronto, serving the Greater Toronto Area.

- **Live:** https://www.wynfordroadsideassistance.com
- **Status:** live, ongoing client work (I'm still working on it with the client)
- **Role:** design and development, by Fahad Jamal ([Code by FJ](https://codebyfj.com))

<a href="https://www.wynfordroadsideassistance.com"><img src="https://raw.githubusercontent.com/codebyfj/codebyfj/main/assets/wynford-preview.gif" alt="Wynford Roadside Assistance homepage on desktop and mobile" width="100%" /></a>

## The brief
A driver stuck on the road should be able to reach the company in one tap, and the owner should be able to run the site without a developer.

## What's in it
- Call and WhatsApp buttons on every screen, plus a 3-step quote form (problem, location, send)
- Live Google reviews pulled from the Google Places API
- Gallery of real jobs from the company's own trucks
- Service area map for the GTA regions they cover
- Admin panel: SEO editor for every page, lead inbox, one-click publish
- Mobile-first layout, since most customers open it on a phone at the roadside

## Stack
React · Vite · Node.js serverless functions · PostgreSQL · Vercel
